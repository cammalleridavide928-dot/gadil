# Gadil Meccanica

Sito aziendale statico in HTML, CSS e JavaScript.

## Pubblicazione su GitHub Pages

1. Carica il contenuto di questa cartella nella radice del repository: index.html deve essere al primo livello.
2. Apri Settings > Pages e scegli Deploy from a branch.
3. Seleziona il branch main e la cartella / (root), poi Save.

Non servono installazioni, compilazioni o modifiche ai file di configurazione. I collegamenti relativi funzionano anche quando il sito si trova sotto il nome del repository.

## Struttura

- index.html: pagina iniziale.
- azienda/, servizi/, personale/, realizzazioni/, contatti/: pagine interne.
- assets/: fogli di stile, script, immagini e icona.
- .nojekyll: pubblicazione diretta dei file statici.
- robots.txt: indicazioni per i motori di ricerca.

Per modificare il sito, intervieni direttamente sui file HTML e sulle risorse in assets/. Per consultarlo in locale, apri index.html nel browser. I caratteri tipografici vengono caricati da Google Fonts; senza connessione vengono utilizzati i caratteri di riserva.
